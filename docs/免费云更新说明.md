# SH启动器免费云更新

SH启动器使用 Tauri 更新签名和 GitHub Releases 下发更新，不需要租用服务器。

## 安全文件

- 更新公钥已经写入启动器，只能用于验证。
- 更新私钥位于 `D:\SHLauncher-Private\sh-launcher-updater.key`，绝对不能放入源码、ZIP 或 GitHub。
- 请把整个 `D:\SHLauncher-Private` 文件夹额外备份到只有开发者能访问的离线设备。丢失私钥后，已经安装的旧版无法验证后续更新。

## 首次启用

1. 创建公开 GitHub 仓库并上传本工程。
2. 在仓库 Settings → Secrets and variables → Actions 中创建：

- TAURI_SIGNING_PRIVATE_KEY：填写 D:\SHLauncher-Private\sh-launcher-updater.key 的完整内容。
- TAURI_SIGNING_PRIVATE_KEY_PASSWORD：当前密钥没有密码，因此可以不创建这个 Secret。

.github/workflows/release.yml 会自动使用当前仓库地址，不需要手写下载服务器地址。

## 每次发布

1. 同时修改 `package.json`、`src-tauri/Cargo.toml` 和 `src-tauri/tauri.conf.json` 的版本号。
2. 推送形如 v0.1.3 的 Git 标签，或者在 GitHub Actions 页面手动运行“发布 SH启动器”。
3. GitHub 会免费完成 Windows 构建、签名、安装包上传和 latest.json 生成。
4. 工作流只创建草稿发布。下载并测试安装包，没有问题后再点击正式发布。
5. 在旧版启动器的“设置 → 启动器更新”中完成一次真实升级测试。

更新程序只替换启动器安装文件，不会删除 `D:\MinecraftLauncherData` 中的游戏、模组、整合包或存档。
