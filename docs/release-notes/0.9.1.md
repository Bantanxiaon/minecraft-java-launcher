## SH启动器 v0.9.1 Beta（更新提速补丁）

- 更新下载多源化：安装包从 GitHub 直链 + ghproxy.net / gh-proxy.com / ghfast.top 三个国内代理镜像中自动选择，单源卡死或极慢（连续 8 秒平均低于 64KB/s）时立即切换，不再等几分钟超时。
- 更新下载全程保持官方 minisign 签名校验：无论从哪个源下载，签名不通过一律拒绝安装。
- 更新进度实时显示当前速度与百分比；检查到更新、安装成功、失败原因都有明确提示。
- 修复 jsDelivr 无法分发安装包（对 .exe 返回 403）导致的“更新没有安装成功”问题，发布链路已改为 GitHub 官方直链。
- 修复启动闪退：0.9.0 的启动小窗与主窗口交接存在竞态，小窗偶发把自己关闭导致程序无窗口后干净退出；现在只有主窗口负责交接，小窗不再自杀。
