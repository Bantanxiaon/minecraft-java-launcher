## SH启动器 v0.9.4 Beta（UI 3.0 第一阶段）

- 生产界面开始接入 UI 3.0（XMCL 现代深色方向）：新增设计令牌（SH Graphite / SH Indigo）与暗色 App Shell，主导航从 11 项收敛为 6 项（首页 / 游戏库 / 发现 / 下载 / 账户 / 设置）。
- 新增独立“账户”页：离线账户创建/切换/移除，外置登录入口，Microsoft 明确标注“后续支持”而非可点击假按钮。
- “发现”页以标签整合模组 / 整合包 / 资源包 / 光影 / 存档，原有功能全部保留。
- 首页 Hero 重做为暗色启动主视觉；启动小窗同步暗色化。
- 新增账户页前端交互测试（3 项）。
- 说明：UI 3.0 属于分阶段迁移，其余页面（下载/存储/设置等）视觉迁移与 XMCL 功能对齐仍在进行中，不会伪装成已完成。
