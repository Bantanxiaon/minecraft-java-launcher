## SH启动器 v0.9.0 Beta（离线版）

- 离线账户体系全量整改：仅大小写不同的同名账户不再重复创建；双击/并发创建恰好成功一次；当前账户持久化，重启自动恢复；删除账户事务化并确定性回退。
- 启动身份冻结快照：启动期间切换账户不影响本轮游戏；游戏时长记录保存“当时是谁在玩”的账户信息，删除账户后仍可审计。
- 标准离线 UUID：与 Java `nameUUIDFromBytes` 逐字节一致；历史存储损坏会自动修复，不再静默生成错误身份。
- 数据库迁移 v10-v12：升级前自动备份并保留最近 5 份；真实旧库原地升级验收数据无损。
- 真机启动矩阵：Vanilla 1.20.1 / 1.20.4 / 1.21.11 与 Forge / NeoForge / Fabric 全部经生产启动路径验收通过。
- 下载稳定性：极慢源改为时间驱动检测（不再要求先积累 256KB 才切换），EXTREME_SLOW / NO_PROGRESS 自动断开并保留续传，可信镜像回退，SHA-1 校验不变。
- 启动与首屏性能：更新检查、完整模组健康扫描移出关键路径；Java 探测只做一次；模组健康按目录指纹增量缓存。
- 窗口行为：单显示器 100% DPI 下显示/尺寸/最小化/最大化自动化验收通过。
- 本版为 Beta 离线版本：Microsoft 正版登录暂未开通；联机（e4mc）为实验性功能，未完成在线端到端验收，不承诺稳定性。
