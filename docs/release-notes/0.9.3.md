## SH启动器 v0.9.3 Beta（P0 稳定性 + 诊断）

- 启动窗口改为唯一状态机（StartupWindowCoordinator）：主窗口显示成功不再等于“真实可见”，必须连续确认可见（含原生 HWND 校验、非最小化、非离屏）后才关闭启动小窗；关闭后 10 秒内监控，异常隐藏自动恢复。彻底消除“进程活着但无窗口”的幽灵状态。
- 新增 Minecraft 崩溃诊断：可解析 MixinTransformerError 的完整 Caused-by 链，提取根因异常、mixin config、mixin class、目标类与 owning Mod JAR 候选（带置信度），不再把包装异常原样甩给用户。
- 新增服务器连接诊断：地址解析（域名/IPv4/[IPv6]:port）、SRV 查询、DNS、TCP 探测与断线分类（认证/版本/白名单/满员/网络等分开显示）。
- 新增 NextGen 基线清单与参考实现登记（docs/nextgen/），为 UI 3.0 与 XMCL 功能对齐做准备。
