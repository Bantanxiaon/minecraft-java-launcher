## SH启动器 v0.8.0

- 依赖解析可信化：不再从 modId 盲猜 Modrinth slug；内置已核对的 provider 别名映射，并为 KotlinForForge / Bookshelf / Prism / Alex's Caves / Iron's Spells / TaCZ / ExpandAbility / fzzy_config / L2Library / Goety 补回归测试。
- 支持 Fabric/Quilt 的 provides 声明，依赖满足按主 modId 或 provides 别名判断。
- 内容来源溯源：Modrinth/CurseForge 安装写入 content_provenance，保留 provider、projectId、fileId、来源 URL 与哈希。
- 标准离线 UUID：按 Java nameUUIDFromBytes 语义生成（MD5 + version 3），并保留旧 SHA-256 UUID 兼容字段。
- 账户身份：display_name 不再作为唯一身份；minecraft_uuid 唯一索引，同名不同身份可共存。
- 存储管理：新增磁盘占用总览、安全清理预览与执行（fingerprint 防 TOCTOU）、已删除实例列表/恢复/永久删除。
- 数据库迁移：新增内容溯源、身份缓存、实例启动设置、受管理内容、整合包来源、删除实例与保留策略表；开启 WAL/busy_timeout，升级前自动备份数据库。
- 下载取消按任务隔离：新增单任务取消命令，任务 A 取消不影响任务 B。
- 一键免费联机 V1：e4mc 作为受管理内容精确安装，启动后自动识别局域网端口与 e4mc 邀请地址。
- 路径安全：统一 Windows 文件名校验（保留设备名、结尾点/空格、禁用字符）。
- 数据目录：优先沿用旧 D 盘数据；无旧数据时使用系统本地应用数据目录，不再要求必须有 D 盘。
- 前端新增 Vitest 测试与 CI 质量门禁；版本号、commit、构建时间注入 BuildInfo。
