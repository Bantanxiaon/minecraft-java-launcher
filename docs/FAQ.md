# 常见问题

## 打不开启动器

重新运行安装程序。安装时保持联网，让它自动补齐显示界面所需的微软组件。不要运行项目目录里的测试程序。

## 提示没有合适的 Java

打开“设置”，点击“检测全部环境”。如果仍然没有，点击“一键安装并验证 Java 21”。老版本游戏需要 Java 8 或 17 时，按启动器提示点击对应版本。

## 模组装了以后游戏崩溃

先关闭最近安装的模组，再检查它是否适合当前 Minecraft 版本和 Fabric、Forge、NeoForge 或 Quilt。提示缺少依赖时，需要把依赖模组也装上。

## 启动器会把游戏放进 C 盘吗

不会。游戏、模组、存档、Java 和日志都放在 `D:\MinecraftLauncherData`。Windows 自己可能在系统区域保存安装记录，这不属于游戏数据。

## 为什么 ZIP 只有几 MB

因为发布包只有启动器，不含 Minecraft 和 Java。创建游戏配置以后，启动器才会从官方网站下载需要的文件。

## 为什么 Windows 显示“未知发布者”

0.1.2 还没有商业代码签名证书。请确认 ZIP 来源可信，并核对 `SHA256SUMS.txt` 的文件完整性编号。编号不同就不要运行。

## 能不能联机

联机页面目前暂缓开放。本地玩家名称不是微软正版登录，不能进入要求正版验证的服务器。

## 为什么 Microsoft 登录显示“暂未开通”

浏览器 OAuth + PKCE 登录后端已经保留，但当前发行包没有发布者合法取得的 Microsoft 应用编号。普通玩家不需要填写 Client ID，也不需要为了本地单机功能注册 Azure 或绑定银行卡。以后发布者取得正规编号并重新打包后，入口会自动启用。
