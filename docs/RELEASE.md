# 从一片星空，进入你的 Minecraft

SHLN 换上了新的星轨首页。账号收进右上角，下载、实例和设置各有自己的位置，打开之后，先选好今天想玩的世界。

这次带来的还有：

- 原版与 Fabric、Forge、NeoForge、Quilt 独立实例。
- 本地 Mod 搜索、批量启停，以及 Modrinth、CurseForge 在线安装和更新。
- 自动或手动分配游戏内存，按实例保存设置。
- 皮肤与披风预览、账号切换、托盘运行和闲置资源清理。

![星轨首页](https://raw.githubusercontent.com/Bantanxiaon/minecraft-java-launcher/main/docs/images/home.png)

## 下载与使用

下载下方的 **SHLN-0.11.0-windows-x64.zip**，解压后运行 `SHLauncher.UI.exe`。压缩包自带 .NET 运行环境；游戏使用的 Java 仍需自行准备。

数据保存在程序旁边的 `data` 文件夹。请保留整个程序目录，升级时尤其要保留 `data`。

这一版采用新的程序结构，请单独解压，不要直接覆盖旧 Rust 版的安装目录。旧版数据不会自动转换。

目前提供 Windows x64 版本。Microsoft 账号登录暂未开放；CurseForge 内容需要自己的应用访问配置。更多说明见[使用说明](https://github.com/Bantanxiaon/minecraft-java-launcher/blob/main/docs/USAGE.md)。
