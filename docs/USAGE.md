# 使用说明

## 安装游戏

在「下载」中选择 Minecraft 正式版，点击「安装所选版本」，选择需要的加载器并命名。安装完成后，在「实例」里选中它，再回到首页启动。快照版本目前仅供浏览。

Java 需要与游戏匹配。在设置里选择本机 Java 的可执行文件；启动器会检查版本与位数。内存设置过高时，先调低数值或释放系统内存。

## 账号

右上角可以切换和管理账号。离线名为 3–16 位英文字母、数字或下划线，适用于单机及允许离线身份的服务器。第三方服务需要公开的 HTTPS 认证地址；只向你信任的服务提交凭据。Windows 的在线会话使用当前系统用户的加密存储。

## 文件放在哪里

Windows 便携包带有 `portable.flag`，数据保存在程序旁的 `data` 目录。实例位于 `data/instances/实例编号/`，其中 `game` 保存 Mod、配置和存档，`runtime` 保存游戏运行文件。不要只复制 EXE，程序文件夹需要完整保留。

可以在启动前通过 `SHLAUNCHER_DATA_DIR` 指定绝对数据路径，它优先于便携目录。源码运行时未设置路径且没有便携标记，使用系统的应用数据目录。

升级请先退出启动器，保留 `data`，替换程序文件。旧 Rust 版的数据不会自动转换为新格式。

## 管理 Mod

选择带有加载器的托管实例，进入 Mod 管理。外部目录只读，避免改动原有游戏。禁用会保留原文件，移除使用系统回收站。在线更新留下的旧文件位于实例的 `.shln-mod-transactions` 目录，确认不再需要前请保留。

如果更新被中断，在在线安装窗口点击「恢复中断的更新」。恢复不需要联网；若文件已被其他程序改动，先保留备份并检查提示，不要直接删除恢复记录。

Modrinth 可直接查询。CurseForge 需要你合法持有的应用访问权限：在数据目录创建 `settings/curseforge.local.json`，内容为一个 JSON 对象，其中 `apiKey` 是你的密钥。也可以用 `SH_CURSEFORGE_CONFIG_FILE` 指定这个文件的绝对路径。修改后重启生效。

密钥不要提交到仓库或发给别人。作者不允许第三方分发时，启动器不会构造替代地址。整合包缺少必需文件时不会发布半成品实例。

## 托盘和退出

设置中可以选择每次询问、退出启动器或最小化到托盘。退出前如有游戏运行，会询问是否结束游戏。正常退出游戏请优先使用游戏里的退出按钮。
