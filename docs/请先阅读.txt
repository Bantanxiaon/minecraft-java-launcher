SH启动器 0.1.2 修复版（Windows 10/11 64位）

最快开始方法
1. 双击“SH启动器 0.1.2 安装程序.exe”。
2. 打开 SH启动器，进入“设置”，点击“检测全部环境”。
3. 如果缺少 Java，点击“一键安装并验证 Java 21”。
4. 点击“新建游戏配置”，选择 Minecraft 版本和需要的模组环境。
5. 点击“开始游戏”。第一次会自动创建 Player 本机测试档案。
6. 启动器会自动下载或校验游戏文件，并自动安装兼容的模组环境。
7. 准备完成后 Minecraft 会自动打开。

请注意
- SH启动器不包含 Minecraft 游戏，也不赠送游戏资格。
- 游戏、模组、存档和 Java 放在 D:\MinecraftLauncherData。
- 联机功能当前暂缓开放。
- Microsoft 正版登录当前暂未开通，不需要填写 Client ID；本地单机启动不受影响。
- 正式版不需要 localhost。看到 localhost:5173 说明误开了开发人员测试程序。
- Windows 可能显示“未知发布者”，因为 0.1.2 还没有商业代码签名证书。请从可信来源获取，并核对 SHA256SUMS.txt 中的文件完整性编号。

模组搜索、整合包、资源包、光影、存档和故障处理，请看“SH启动器 0.1.2 完整使用说明.txt”。
