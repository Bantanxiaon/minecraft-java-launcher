# SH启动器 0.1.3 完整使用说明

这份说明写给第一次使用 Minecraft 第三方启动器的玩家。按顺序操作即可，不需要会编程。

## 一、先看这几件事

- SH启动器只是打开和管理游戏的工具，不包含 Minecraft 游戏本体。
- 你需要自己拥有合法的 Minecraft 游戏资格。
- 当前发行包使用“本地玩家名称”。Microsoft 正版登录因发布者尚无合法应用编号而标注“暂未开通”，普通用户不需要填写 Client ID。
- 联机页面现在只是预留位置，暂时不能使用。
- 游戏、模组、存档和 Java 都放在 `D:\MinecraftLauncherData`，请保证 D 盘空间充足。

## 二、安装

1. 解压收到的 ZIP 文件。
2. 双击“SH启动器 0.1.3 安装程序.exe”。中文 Windows 默认显示简体中文安装界面。
3. 一直按照安装窗口提示操作。
4. 如果电脑缺少显示启动器界面所需的微软组件，安装程序会自动联网补装。
5. 安装完成后，从开始菜单打开“SH启动器”。

补充说明：Windows 可能提示“未知发布者”，因为 0.1.3 还没有购买商业代码签名证书。请确认 ZIP 来自可信的人，并核对 `SHA256SUMS.txt` 中的文件编号；编号不同就不要运行。

## 三、第一次打开

### 1. 检查运行环境

1. 打开左侧“设置”。
2. 点击“检测全部环境”。
3. 如果提示没有可用 Java，点击“一键安装并验证 Java 21”。
4. 等待下载和检查完成，不要中途关闭启动器。

如果电脑已经通过 PCL、官方启动器或其他启动器下载过游戏，在设置里的“已有游戏目录”点击“选择文件夹”，选择对应的 `.minecraft`。保存后，SH启动器会先复用校验通过的文件，只下载缺少或损坏的部分。

Java 是 Minecraft 运行时需要的基础程序。不同 Minecraft 版本可能需要 Java 8、17、21 或 25；启动器会提示正确版本。Java 17/21/25 从 Microsoft 官方 CDN 下载，Java 8 使用 Eclipse Temurin，都会校验 SHA-256。

### 2. 本机测试档案

直接点击“开始游戏”即可。第一次启动时，启动器会自动创建名为 `Player` 的本机测试档案。也可以在主页底部自行改用 3–16 位字母、数字或下划线组成的名称。

这个名称只保存在本机，不是微软登录，也不会冒充正版账号。

## 四、创建一套游戏

启动器把每一套游戏版本、模组和存档分开保存，这里叫“游戏配置”。例如，你可以同时保留一套纯原版和一套 Fabric 模组游戏，它们不会互相影响。

1. 在主页点击“新建游戏配置”。
2. 给它起一个容易认出的名字，例如“1.21.1纯原版”或“冒险整合包”。
3. 选择 Minecraft 版本。
4. 选择模组运行环境：
   - Vanilla：纯原版，不使用模组运行环境。
   - Fabric：轻量，常见模组很多。
   - Quilt：与 Fabric 相近，但模组仍要确认兼容。
   - Forge：许多老牌和大型模组使用。
   - NeoForge：较新版本常见，不能简单当成 Forge 使用。
5. 点击“创建游戏配置”。
6. 点击“开始游戏”。启动器会自动检查并补齐基础游戏文件；如果选择了 Fabric、Quilt、Forge 或 NeoForge，还会自动选择兼容版本并安装对应环境。
7. 文件、Java 和模组环境都准备好后，Minecraft 会自动启动。

第一次下载可能较慢。中途取消后，已经下载的临时文件会保留，下次可以继续。

## 五、从启动器里搜索模组

1. 打开左侧“模组”。
2. 先选择“安装到哪套游戏”。纯原版不能安装这类模组。
3. 在“在线搜索模组”输入名称或关键词，例如 `sodium`。
4. 点击“搜索”。结果来自 Modrinth（一个常用模组下载平台），并且已经按当前 Minecraft 版本和模组环境筛选。
5. 选择想要的项目，点击“下载并安装”。
6. 启动器会检查下载地址、文件大小、文件完整性和模组说明。
7. Modrinth 中声明为“必须”的依赖会按顺序自动安装；本地 JAR 无法确定远程项目时会把依赖名称说清楚，由用户确认来源。

模组文件可以在游戏里执行程序。只安装你信任的作者或平台提供的模组；“文件完整”不代表模组一定没有恶意内容。

## 六、导入电脑里的模组

1. 打开“模组”，选择要安装到哪套游戏。
2. 点击“选择本地模组文件”，可以一次选择多个 `.jar` 文件；也可以直接拖进窗口。
3. 启动器会读取模组自带说明，检查它适合 Fabric、Forge、NeoForge 还是 Quilt。
4. 看清版本不匹配、重复模组、冲突或缺少依赖的提示。
5. 确认后安装。安装过的模组可以暂时关闭、重新启用或移到备份区。

`.jar` 是 Minecraft 模组常用的文件格式。

## 七、在线下载整合包

整合包是一套已经搭配好的游戏版本、模组和设置。

1. 打开“整合包”。
2. 在“在线搜索整合包”中输入名称或玩法关键词。
3. 点击“下载并安装”。
4. 启动器会从 Modrinth 下载整合包，检查文件完整性，然后创建一套新的独立游戏配置。
5. 导入完成后回到主页，按提示下载 Mojang 游戏文件并安装模组运行环境。

大型整合包第一次启动可能需要较长时间。建议分配 6–8 GB 内存，但不要超过电脑物理内存的一半到三分之二。

## 八、导入电脑里的整合包

可以点击选择，也可以把文件拖到整合包页面：

- `.mrpack`：Modrinth 整合包文件，可自动创建新游戏配置。
- CurseForge 导出的 `.zip`：会导入压缩包里允许直接使用的文件；平台不允许直接下载的项目会列出来。
- 普通 `.zip`：会先检查文件结构和大小，再导入能识别的内容。

启动器不会绕过平台限制去偷下作者不允许分发的文件。

### 导出自己的整合包

在“整合包”页面选择实例后点击“导出 ZIP”。默认包含模组、设置、资源包、光影、`options.txt` 和 `servers.dat`；存档默认不包含，只有主动勾选才加入。账户、Microsoft Token、启动器数据库和私人凭据永远不会导出。

## 九、资源包和光影

1. 打开“资源包”或“光影”。
2. 选择一套游戏配置。
3. 选择压缩包，或直接拖进窗口。
4. 导入后可以启用、停用或移除。

资源包会改变方块、物品和界面外观。光影会改变灯光和画面效果，通常还需要 Iris 或 Oculus 等配套模组；显卡性能不足时可能明显掉帧。

## 十、导入存档

1. 打开“存档”。
2. 选择要放进哪套游戏。
3. 点击“选择文件夹”或“选择压缩包”，也可以直接拖入。
4. 启动器会自动寻找存档需要的 `level.dat` 文件。
5. 遇到同名存档会自动换一个名称，避免覆盖原存档。

每个存档都可以备份、复制或导出 ZIP。移除存档时会先放到备份区，可在同一页面恢复。重要存档仍建议另外复制一份保存。

## 十一、下载失败或游戏打不开

按这个顺序检查：

1. 打开“下载”页面，看具体任务、崩溃建议和脱敏游戏日志；日志可按 INFO/WARN/ERROR/DEBUG 和关键词筛选。
2. 确认网络正常、系统时间正确、D 盘还有空间。连续 60 秒没有收到下载数据时会明确报错并保留可续传文件，不会无限卡住。
3. 在“设置”点击“检测全部环境”。
4. 确认当前游戏需要的 Java 版本与所选 Java 一致。
5. 新装模组后崩溃，先关闭最近加入的模组，再检查缺少依赖或模组冲突。
6. 仍然无法解决时，在“下载”页面导出诊断报告，发给维护者。

诊断报告会尽量隐藏个人路径等信息，发送前仍建议自己打开看一遍。

## 十二、看到“localhost 拒绝连接”怎么办

正式安装版不需要 localhost。如果看到这个页面，说明你打开的是开发人员测试用程序，并且它的临时网页服务已经关闭。

处理方法：关闭该窗口，然后运行从本 ZIP 安装的“SH启动器”。不要运行项目文件夹里的 debug 程序。

## 十三、升级和卸载

- 正式启用云更新后，可在“设置 → 启动器更新”检查并安装新版。更新包必须通过内置签名校验，失败时继续保留旧版。
- 也可以先退出游戏和启动器，再手工运行新版安装程序。
- 卸载启动器时不会自动删除 D 盘游戏数据，避免误删存档。
- 如果确定全部不要了，先备份存档，再手工删除准确的 `D:\MinecraftLauncherData` 文件夹。

## 十四、文件完整性编号怎么核对

发布包中的 `SHA256SUMS.txt` 记录安装程序的完整性编号。普通用户可以不操作；如果需要确认文件没有被替换，可在 ZIP 解压目录打开 PowerShell，运行：

`Get-FileHash '.\SH启动器 0.1.3 安装程序.exe' -Algorithm SHA256`

命令显示的长编号应与 `SHA256SUMS.txt` 完全一样。
